# Parth Srivastava - AI/ML Engineer Portfolio

An interactive, high-performance web portfolio for **Parth Srivastava**, featuring:
- **LLM Fine-Tuning Showcase**: Custom Qwen2.5-0.5B SFT with QLoRA & Hugging Face models.
- **RAG Architecture & AI Agents**: Enterprise vector synchronization and multi-agent workflows.
- **Interactive AI Simulators**: Real-time Qwen2.5 JSON Extractor & LangGraph Synthetic Data Generator.
- **Serving & Infrastructure**: vLLM, Docker, RunPod, FastAPI, and Prometheus monitoring.

## 🚀 Live Demo & Local Setup
